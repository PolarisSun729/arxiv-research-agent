# 证据需求账本使用受控状态转移

LLM 角色只能提出新增、确认、拆分、阻塞或撤销证据需求的命令，确定性 Ledger Reducer 校验身份、父子关系、核心需求保护和合法状态转移后才应用；LLM 不得直接返回覆盖后的完整账本。只有 CoverageProjector 能依据已通过主张—证据校验的引用把需求标记为满足，证据失效时覆盖也可回退；该设计保留动态研究能力，同时防止 Agent 通过删除、降级或自行满足核心需求来改变完成标准。

实施分期：当前第一切片只实现初始需求归一化、核心需求存在性/父子关系校验，以及基于当前草稿重新投影并可回退的覆盖状态。运行中的新增、确认、拆分、阻塞和撤销命令及通用 Ledger Reducer 留到下一切片；在此之前，模块不对外宣称已支持账本结构动态演进。
