# 论文研究助手

面向论文检索、论文问答和个性化论文发现的研究辅助系统。系统以可追溯的论文证据支持回答，并区分用户的长期研究兴趣与当前研究任务。

## Language

**论文问答**:
用户围绕指定论文提出问题，并要求回答能够追溯到该论文中的证据。
_Avoid_: 普通问答、聊天问答

**研究问题**:
原始用户问题结合已解析的目标论文与会话语境完成消歧后，形成的自包含取证目标；它不等同于任一轮使用的具体检索查询。
_Avoid_: 改写问题、检索问题、搜索词

**证据片段**:
能够直接支持一个或多个回答主张的论文内容单元；仅与问题相似但不能支持主张的内容不属于有效证据。
_Avoid_: 上下文、搜索结果、相关文本

**证据候选**:
根据检索相关性或结构信息判断可能与某项证据需求有关、但尚未确认能够直接支持该需求的论文内容单元。
_Avoid_: 证据片段、已支持证据

**证据包**:
一个主要证据候选连同理解它所必需的结构上下文组成的选择单位，例如文本及章节标题、表格单元格及行列头，或图片及标题和引用段落。
_Avoid_: ContextPack、单个 chunk、全部检索结果

**纯视觉主张**:
必须读取图片中的坐标轴、图例、曲线、区域或视觉数值才能判断的回答主张；只有图注或周围正文相关而未校验图片本身时，不视为已获得支持。
_Avoid_: Figure caption 主张、图片相关文本、普通多模态输入

**回答主张**:
从用户可见答案文本中识别出的、可以独立判断是否被论文证据支持的原子事实、比较、数值或结论；生成器声明可以辅助定位，但不能替代对实际答案文本的独立识别。
_Avoid_: 句子、生成内容

**有限推断**:
由已获证据支持的明确前提形成、推断关系和措辞强度均可校验的综合结论；它必须与论文直接报告和确定性数值推导区分，不能引入论文外部前提。
_Avoid_: 作者结论、自由分析、合理猜测

**证据需求**:
为了完整回答当前问题而提出的事实或论证目标；它最初可以处于待确认状态，只有确认必要后才纳入证据覆盖判断，并可随研究进展被拆分或撤销。
_Avoid_: 子问题、检索词、搜索计划

**证据需求账本**:
记录证据需求当前状态、来源和演进关系的受控研究账本；研究角色可以提议变化，但只有经过校验的证据覆盖能够将需求标记为满足。
_Avoid_: 固定研究计划、任务列表、LLM 输出快照

**证据覆盖**:
一组证据片段对当前已确认的全部证据需求的支持情况；待确认或已撤销的需求不参与覆盖判断，相关但不能直接支持需求的片段也不计入覆盖。
_Avoid_: 召回率、相似度、上下文数量

**有限回答**:
所有保留下来的事实主张均有证据支持，但只覆盖用户问题中部分已确认核心需求的回答；它表达可靠但不完整，不代表允许无支持或低置信主张。
_Avoid_: 部分正确答案、低质量答案、猜测性回答

**证据拒答**:
证据研究已正常完成，但没有形成能够支持用户问题核心结论的可靠证据，因此明确不给出实质性结论；它是业务终态，不属于系统执行失败。
_Avoid_: 问答失败、系统错误、空答案

**证据缺口**:
尚未获得充分证据支持的证据需求，或者已有证据相互冲突、无法形成可靠结论的需求。
_Avoid_: 空结果、低分片段、检索失败

**引用错配**:
回答主张标注的引用不能支持该主张，但当前证据候选池中存在可支持它的其他片段；错配必须修正并重新校验，不能直接视为主张已获支持。
_Avoid_: 证据缺口、无支持主张、引用格式错误

**修复检索**:
由证据缺口触发、只针对未满足需求进行的后续取证过程。
_Avoid_: 重试、重复搜索、查询改写

**中立取证任务**:
描述待核实对象、比较条件和期望证据形态，但不把待验证结论预设为事实的检索目标；其结果允许支持、部分支持、反驳或未报告当前主张。
_Avoid_: 证明性查询、答案导向搜索、底层检索参数

**证据研究子图**:
围绕单篇论文动态决定检索、形成草稿、校验证据或停止回答的有界研究过程；它不负责通用任务规划或底层索引实现。
_Avoid_: 问答流水线、通用 Agent、检索服务

**证据研究运行**:
证据研究子图针对一次论文问答产生的独立、可恢复执行实例；运行是否成功与最终形成完整回答、有限回答或证据拒答是两个不同维度。
_Avoid_: 工具调用、聊天会话、问答结果

**证据研究结果**:
证据研究运行正常结束后形成的完整回答、有限回答或证据拒答及其已验证引用；系统执行失败不属于研究结果，而属于运行失败。
_Avoid_: 运行状态、失败载荷、工具错误

**研究摘要**:
面向用户和外层 Agent 的证据研究结果概览，只呈现取证次数、覆盖情况、未解决主题和终止原因，不暴露内部调试细节。
_Avoid_: 研究轨迹、调试信息、完整执行状态

**研究轨迹**:
按时间追加的结构化研究事件，用于回放证据需求、动作、候选、主张校验和修复过程；它不是当前业务状态真源，也不记录模型隐藏思维过程。
_Avoid_: 日志文本、checkpoint、思维链

**证据评估样本**:
围绕一篇论文和一个研究问题，连同可回答性、证据需求、回答主张及其证据定位共同标注的评估单位；它用于判断证据覆盖与自修复，而不只是评价文字表达。
_Avoid_: 测试问题、标准答案、人工评分项

**自修复增益**:
同一研究运行中，修复动作执行后相对于初稿新增的可靠主张支持或核心证据覆盖；它必须和修复成本及有害修复一起解释。
_Avoid_: 答案变长、相似度提升、重试次数

**长期研究兴趣**:
由跨论文、跨会话的稳定用户信号形成的研究方向偏好，不应被单次查询直接覆盖。
_Avoid_: 当前兴趣、搜索关键词

**当前研究意图**:
用户在本次查询或会话中希望解决的具体研究问题，可以暂时偏离长期研究兴趣。
_Avoid_: 用户画像、长期偏好

**推荐候选**:
尚未被明确排除、可参与个性化排序的论文；候选资格不代表最终值得推荐。
_Avoid_: 推荐结果、搜索结果
