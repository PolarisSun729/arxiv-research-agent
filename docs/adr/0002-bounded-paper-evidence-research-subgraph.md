# 使用独立的有界论文证据研究子图

单篇论文的动态取证、回答生成与主张校验由独立证据研究子图持有，外层 `arxiv_search_agent` 只负责通用任务规划、目标论文解析和调用子任务，底层检索服务继续只执行查询。外层继续通过稳定的 `answer_paper_question` 工具调用该能力，子图的动态循环不暴露成外层计划步骤。外层向子图传入原始问题和会话快照，子图负责将其消歧为自包含的研究问题，避免通用 Agent 侵入论文内部语义。子图维护可演进的证据需求账本：初始需求只是待确认项，后续可依据检索观察和草稿校验新增、拆分、满足、阻塞或撤销，而不是在运行前固定完整取证计划。下一项研究动作由 LLM 根据当前证据语义提出，再由确定性准入层校验动作结构、预算、状态前置条件与重复执行风险；规则不直接判断论文内容是否支持主张。每轮检索结果先以稳定标识归一化并合并进跨轮证据候选池，只有生成草稿或校验主张时才围绕当前需求选择候选并构建临时上下文包，避免把单轮召回结果误当成最终证据或在状态中重复保存生成上下文。草稿生成器可以声明主张与引用，但待校验主张必须由独立提取器从用户实际可见的答案文本中重新识别，并以两者对齐后的实际文本主张作为校验真源，避免遗漏生成器未主动声明的断言。校验先严格检查主张实际引用；引用不支持时，只允许在已有候选池内进行有界证据找回，找到其他支持片段也只能产生引用修复或主张收窄动作，修改并重新校验后才可通过，避免为既有结论重新搜索合理化依据。校验器给出的 `supported` 标签只有在绑定非空证据 ID，且所有证据 ID 都能回指当前候选池原文时，才可进入需求覆盖和完成判断。最终答案中所有可验证主张都必须获得支持；核心需求全部满足时才返回完整回答，只满足部分核心需求时必须删除或收窄无支持内容、重新校验后返回可靠但不完整的有限回答。完整回答、有限回答和证据拒答都属于工具成功；研究模块只返回这些正常业务结果，模型、索引、状态或持久化等系统异常通过结构化异常离开模块，由工具 Adapter 映射为失败并记录运行失败，避免调用方把系统错误当作普通研究结果，也避免外层恢复策略对合法拒答反复重跑。每次调用创建带稳定 `research_run_id` 的独立证据研究运行，以内层 checkpoint 和动作幂等记录恢复昂贵节点；恢复时锁定论文索引版本，外层重复调用优先返回或继续既有运行，而不是重启整套研究。正常响应只返回研究摘要与 `research_trace_id`，完整研究轨迹以追加式结构化事件独立持久化并通过受控调试接口查询；轨迹用于回放和评估，不作为业务状态真源，也不记录隐藏思维过程。子图对外返回最终回答、证据包与研究轨迹引用，确保被校验的文本就是用户最终看到的文本，避免外层再次生成时引入未经验证的新主张。该边界也避免把循环取证隐藏在 `PaperQAService` 中形成不可观察的嵌套 Agent，或让通用 Agent 了解论文证据状态、主张校验和停止策略等领域细节；子图通过检索次数、草稿次数、无进展次数、候选条目数和候选累计字符数限制自治范围。
